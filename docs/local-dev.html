Local dev startup guide — run these commands before logging in
One-time setup — only run once, ever.   Every time — run each dev session.
Step 1 One-time setup
1
Generate JWT keypair and add to .env
Generates an RSA keypair and appends the base64-encoded values to server/.env. Only do this once — regenerating will invalidate any existing tokens.
Run in: server/
cd /Users/hephaestus/Projects/ad_lite/server

openssl genrsa -out /tmp/adlite.pem 2048
openssl rsa -in /tmp/adlite.pem -pubout -out /tmp/adlite.pub

echo "JWT_PRIVATE_KEY_B64=$(base64 -i /tmp/adlite.pem)" >> .env
echo "JWT_PUBLIC_KEY_B64=$(base64 -i /tmp/adlite.pub)" >> .env
echo "PORTAL_ORIGIN=http://localhost:3000" >> .env

rm /tmp/adlite.pem /tmp/adlite.pub
Check first: run grep JWT_PRIVATE_KEY_B64 .env — if it already has a value, skip this step.
Step 2 Every time
2
Start Postgres and Redis
Terminal 1
Starts the database and cache in the background. Safe to run if they're already up.
Run in: server/
cd /Users/hephaestus/Projects/ad_lite/server
docker compose up -d
First time only (or after a reset): if you wiped the Docker volume, the migrations run automatically on first boot. Wait ~5 seconds for Postgres to be ready before running the seed.
Step 3 Every time
3
Seed the database
Terminal 1 (same window)
Creates the admin user and demo data. Safe to re-run — it checks before inserting and skips existing records.
Run in: server/
cd /Users/hephaestus/Projects/ad_lite/server
go run ./cmd/seed/main.go -demo
Step 4 Every time
4
Start the Go API server
Terminal 2
Starts the API on :8080. Keep this terminal open — it shows request logs. If port 8080 is already in use, kill the old process first.
Run in: server/
cd /Users/hephaestus/Projects/ad_lite/server
go run ./cmd/api/main.go
If port 8080 is already in use:
lsof -ti :8080 | xargs kill -9
Step 5 Every time
5
Start the Nuxt portal
Terminal 3
Starts the frontend on :3000. First run will take ~15 seconds to compile.
First time only — install dependencies:
cd /Users/hephaestus/Projects/ad_lite/portal
npm install
Every time — start dev server:
cd /Users/hephaestus/Projects/ad_lite/portal
npm run dev

Nuclear reset — wipe all data and start fresh
Destroys the Postgres and Redis volumes. All data is lost. Migrations re-run automatically on next docker compose up.

docker compose down -v
docker compose up -d
